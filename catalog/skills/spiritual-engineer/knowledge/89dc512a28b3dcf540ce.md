# 西洋占星術のエレメントと IT 技術
一見すると、ITとスピリチュアルは関係ないように思えるが、実は深いつながりがある。時代ごとに変わるIT技術のトレンドには、その時代のスピリチュアルな性質が反映されている。
この章では、西洋占星術のエレメントをもとに、スピリチュアル性質とIT技術の関係について述べていく。

## 西洋占星術のエレメント
西洋占星術のエレメントには、「火」「地」「風」「水」の4つがあり、200年周期で「火 → 地 → 風 → 水」の順に移り変わっていく。
各エレメントに対応する時代には、そのエレメントの性質が色濃く反映されており、それぞれの特徴は次の通りである。
|エレメント|時代|エレメントの性質|時代の特徴|備考|
|:-----------|:-----------|:-----------|:-----------|:-----------|
|水|1200 年代～ 1400 年代|感情、協調性、愛情、神聖|・宗教改革||
|火|1500 年代～ 1700 年代|情熱|・革命の多発||
|土|1800 年代～ 2020 年|現実性、実行力、努力、堅実、秩序|・お金や地位によって順序をつける階級社会(中央集権型社会)<br>||
|風|2021 年からの約 200 年間|技術、個人意志、情報、フラットなコミュニケーション|・個人意志を重んじるフラットな社会(分散型社会)<br>・IT 技術の繁栄期<br>||

## IT と西洋占星術のエレメント

### モノシリックとマイクロサービス
ITシステムは、大きく「モノシリック」と「マイクロサービス」の2つに分類できる。

2. マイクロサービス

| IT システムの種類  | 説明                                                                       | 代表技術                                        | 西洋占星術のエレメント | 備考                                                    |
| :------------------ | :-------------------------------------------------------------------------- | :----------------------------------------------- | :---------------------- | :------------------------------------------------------- |
| ① モノシリック     | 必要な機能を可能な限り1つのサーバに集約することで構成される、統合型システム	    | 従来の IT システム全般                          | 土(中央集権)           |                                                         |
| ② マイクロサービス | 各機能を分割し、それらが連携して動作する仕組みを持つ分散型システム	 | ブロックチェーン、コンテナ技術(Kubernetes など) | 風(分散型)             | その他分散型技術<br>・Git<br> ・AI マルチエージェント |

土の時代では中央集権型社会が形成され、ITシステムはモノシリック型が主流だった。一方で、風の時代では分散型社会へと移行し、IT技術はマイクロサービス型へとシフトしている。
土の時代は、富と権力が一部の層に集中していた時代だった。しかし風の時代では、それらが分散し、より多くの人々が豊かさを享受できる社会が到来すると考えられる。
マイクロサービスや他の分散型技術は、それぞれの個性が互いに結びつき、協力し合う未来を示唆しているとも言える。

### トレンドのエンジニアリング手法と風のエレメント
最近のエンジニアリング手法では、アジャイルおよびスクラム開発、DevOpsがトレンドとなっている。それぞれについての一般的な概要と、本質的な意味を以下にまとめてみた。
|エンジニアリング手法|一般的な概要|本質的な意味|備考|
|:-----------|:-----------|:-----------|:-----------|
|アジャイル及びスクラム開発|小規模または中規模の単位で設計・実装・テストを繰り返しながら進めていくシステム開発手法|エンジニアの主体性を重んじた開発手法||
|DevOps|システム開発と運用を統合し、効率的かつ継続的に改善していく仕組み|開発者と運用者が垣根を越えてフラットな関係で協力し合う|||

この表からも分かるように、これらの手法の本質的な意味は「風の時代」の特徴を反映している。
## 補足:日本人本来の精神性と分散型IT技術
### 縄文時代の日本とDAO
縄文時代の日本では、価値観が一致する人々がコミュニティ（村）を形成し、個人の意思を尊重する多様性社会が築かれていた。そのため、村同士や個人間での争いはほとんどなかったと言われている。
![3.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4040756/e4ce424c-dfa3-4ec3-8102-6ecaa05201f3.png)

この縄文時代の村の構造は、DAO（分散型自律組織）と呼ばれる次世代型ブロックチェーン組織と似ている。DAOには中央管理者が存在せず、コミュニティの全メンバーが平等に投票権を持つ仕組みが特徴的だ。この点で、DAOは「風の時代」を象徴する存在といえるだろう。
![4.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4040756/cc7bac3c-029e-415e-914c-7d53a675cca3.png)

また、DAOの特徴が縄文時代の日本社会と似ていることから、日本人本来の精神には、**個人の意思を尊重する多様性を重んじる理念**が深く根付いていると考えられる。
この精神は、さらに遡ればレムリア文明にその源を求めることができる。

### 「和多志」という漢字
技術登壇の際に、「和多志」という漢字をよく使用している。この漢字は「私」の本来の表記であり、言霊としての意味も持つ。
日本人は古来から、漢字や言葉にスピリチュアルな意味（言霊）を込めてきた。しかし、第二次世界大戦後、とある闇組織が霊性の高まりを恐れ、こうした言葉や漢字を排除した歴史がある。
「和多志」という言葉には、多様な個性が結びついて調和を生み出すという意味が込められている。その意味から、個々の個性がつながり合う分散型IT技術と「和多志」との間には共通点があるように感じられる。このことから、本来の日本人の精神性と分散型IT技術には、何らかの関係があるのではないかとも考えられる。
